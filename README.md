# Inventory Management System

A basic inventory management project I built using PHP and MySQL while learning backend development.

The main idea was to understand how PHP works with MySQL and how things like login, sessions and CRUD operations are handled.

## Features

- Login and logout
- Add, edit and delete products
- View all products
- Search products
- Low stock indication
- Basic inventory dashboard
- Session based authentication

## Tech Used

- PHP
- MySQL
- HTML
- Bootstrap
- XAMPP

## Running the Project

1. Clone the repository
2. Move the project to the XAMPP `htdocs` folder
3. Create the `inventory_management` database in MySQL
4. Update database details in `config.php`
5. Start Apache and MySQL from XAMPP
6. Open `http://localhost/inventory-management/`

This was mainly a learning project, so I kept the implementation simple and focused on understanding PHP, MySQL, authentication and CRUD operations.
